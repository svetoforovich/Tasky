# Tasky

Задачи в виде мыльных пузырей. Чем важнее задача и чем ближе дедлайн, тем больше пузырь. Если дедлайн прошёл, пузырь лопается, а задача попадает в «Мёртвые задачи».

Это PWA: одно приложение для телефона и компьютера, устанавливается на главный экран и работает без интернета. Задачи хранятся в браузере (localStorage) на том устройстве, где их создали.

## Установка на телефон (Android)

Откройте раздел [Releases](../../releases/latest), скачайте **Tasky.apk** на телефон и откройте файл. Если телефон спросит, разрешите установку из этого источника. Новые версии ставятся поверх старой, задачи сохраняются.

APK собирается автоматически (GitHub Actions, `.github/workflows/android.yml`) при каждом изменении ветки `main`.

## Запуск в браузере

Откройте `index.html` через любой статический сервер, например:

```
python3 -m http.server 8000
```

и перейдите на http://localhost:8000. Для публикации подойдёт GitHub Pages (Settings → Pages → ветка `main`, папка `/`).

## Файлы

- `app.html` — исходник приложения (разметка, стили и логика).
- `build.py` — собирает из него `index.html` с манифестом и service worker: `python3 build.py`.
- `android/`, `capacitor.config.json` — Android-приложение (Capacitor), которое показывает то же приложение.
- `keystore/debug.keystore` — ключ подписи APK, чтобы обновления ставились поверх.
- `manifest.webmanifest`, `sw.js`, `icon*.{svg,png}` — установка и офлайн-режим.
